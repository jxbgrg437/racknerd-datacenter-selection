## 下單前先 Ping：各機房測試 IP 清單

每個機房都有對應的測試 IP，下單前 ping 一輪再決定。常用的幾個如下：

| 亞特蘭大 | 107.173.164.160 |
| 阿什本 | 192.3.254.158 |

| 斯特拉斯堡 | 45.95.173.2 |
| 都柏林 | 23.95.225.2 |

測法很簡單：Windows 開命令提示字元輸入 `ping 204.13.154.3`，Mac 和 Linux 開終端機用同樣的指令，看平均延遲那一行。低於 150ms 屬於優秀，200ms 以內都算可用。

比 ping 一次更重要的是測法本身，只測一輪很容易被「好日子」騙到：

1. 早上、下午、晚高峰（晚上 8 點到 12 點）各測一輪，你自己實際使用的時段最重要
2. 同時看丟包率和延遲波動——延遲 160ms 但丟包 10%，用起來不如延遲 190ms 卻幾乎零丟包的
3. 判斷標準看最差時段的表現，別只盯平均值
